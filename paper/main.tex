\begin{abstract}
Autonomous driving and intelligent systems require rigorous testing before deployment. Traditional testing approaches often struggle due to the oracle problem in machine learning systems. This paper presents AutoMR, a generalized framework for automated metamorphic testing that supports multiple input modalities, automated transformation generation, violation detection, severity analysis, and real-time validation. Experimental evaluation demonstrates the effectiveness of AutoMR in identifying robustness issues in autonomous driving models under environmental and behavioral perturbations.
\end{abstract}
