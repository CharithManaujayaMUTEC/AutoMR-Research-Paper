\section{Related Work}

Several metamorphic testing frameworks have been proposed for machine learning systems.

DeepXplore introduced neuron coverage guided testing for deep neural networks. DeepTest extended testing to autonomous driving models using realistic image transformations. DeepRoad focused on weather-based scenario generation. DeepGauge introduced multi-granularity testing criteria for deep learning systems.

While existing approaches provide valuable testing capabilities, many focus on specific domains or transformation categories. AutoMR aims to provide a generalized framework supporting automated execution, extensibility, severity analysis, and real-time validation.
