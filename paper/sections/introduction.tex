\section{Introduction}

Modern autonomous driving and intelligent systems increasingly rely on machine learning models to make safety-critical decisions. Ensuring the reliability of these systems before deployment remains a major challenge because correct outputs are often unknown for unseen inputs.

Metamorphic Testing (MT) addresses this challenge by validating relationships between multiple executions of a system rather than relying on explicit test oracles. By applying controlled transformations and verifying expected behavior, MT can reveal hidden defects and robustness issues.

This paper introduces AutoMR, a generalized framework for automated metamorphic testing of autonomous driving and intelligent systems. AutoMR supports automated transformation execution, relation verification, severity analysis, and real-time testing using live camera streams.

The main contributions of this work are:

\begin{itemize}
\item A generalized automated metamorphic testing framework.
\item Support for image, weather, temporal, and behavioral metamorphic relations.
\item Automated violation detection and severity analysis.
\item Real-time validation using webcam-based input streams.
\item An extensible architecture for future intelligent systems.
\end{itemize}
